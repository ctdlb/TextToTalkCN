# 汉化重构说明

本目录记录 `TextToTalkCN` 相对上游 `karashiiro/TextToTalk`（main 分支）的改动。

## 1. 构建适配（国服）

上游把 Dalamud 库路径写死为 `%APPDATA%\XIVLauncher\addon\Hooks\dev`，国服 XIVLauncherCN 下会直接找不到 `Dalamud.dll`，导致还原/编译失败。

改为统一在 `src/Directory.Build.props` 中解析，优先级：

1. 环境变量 `DALAMUD_HOME`
2. `%APPDATA%\XIVLauncherCN\addon\Hooks\dev`
3. `%APPDATA%\XIVLauncher\addon\Hooks\dev`

同时移除了三个项目中各自的硬编码赋值：

- `src/TextToTalk.Lexicons.Updater/TextToTalk.Lexicons.Updater.csproj`
- `src/TextToTalk.Tests/TextToTalk.Tests.csproj`
- `src/LexiconRepoCheck/LexiconRepoCheck.csproj`

## 2. 全量汉化

### 2.1 资源键

| 项目 | 数量 |
| --- | --- |
| 上游英文键 | 135 |
| 上游已有中文键 | 213 |
| 本次新增键 | 243 |
| 合并后英文键 | 378 |
| 合并后中文键 | 456 |

新增键来自 `loc/*.json` 六个片段：

| 片段 | 覆盖范围 |
| --- | --- |
| `core.json` | 后端显示名、命令说明、`/tttpreset`、`/tttvolume` 输出、限流提示 |
| `polly-azure.json` | AWS Polly、Azure 认知服务、Azure 语音风格窗口 |
| `elevenlabs-fishaudio.json` | ElevenLabs、Fish Audio 及其风格窗口 |
| `openai-uberduck.json` | OpenAI、Uberduck、OpenAI 风格窗口 |
| `system-kokoro-google.json` | Windows 系统语音、Kokoro、Google Cloud |
| `websocket-megaphone.json` | WebSocket 端口/地址设置、Megaphone、Google 凭据组件 |

### 2.2 代码改动

- 所有 `ImGui.*` 控件标签、提示、错误行、表格列名、工具提示、输入框 hint 均改为 `Strings.Get("键")` 或 `Strings.键`。
- `TTSBackend.GetFormattedName()` 的后端名称走资源（`BackendName*`）。
- `/tttpreset`、`/tttvolume` 等命令说明与聊天输出走资源（`Command*`、`*Format`）。
- ElevenLabs / Fish Audio / OpenAI 的限流警告走资源（`RateLimitWarning*`）。
- 保留了全部 `##{MemoizedId.Create()}` ImGui ID、`{0}` 占位符与 `string.Format` 的参数顺序。

### 2.3 未翻译的内容（有意保留）

- 日志（`Log.*` / `DetailedLog.*`）、异常类型名、HTTP 状态码。
- API 参数值：模型 ID（`eleven_v3`、`s2.1-pro`）、语言代码、性别枚举、`Speaker`、`Hyur` 等合成请求数据。
- URL、文件路径、ImGui 纯 ID。
- Windows 语音名称（如 `Microsoft Zira`）与第三方产品名。

## 3. 工具链

- `scripts/build.ps1`：自动定位 .NET 10 SDK 与 Dalamud，构建并可 `-Install` 到 `devPlugins`。
- `scripts/merge-loc.ps1`：把 `loc/*.json` 键片段合并进 `.resx` 与强类型访问器，幂等。
- `scripts/check-loc.ps1`：检查代码引用但资源缺失的键。
- `docs/LOCALIZATION_GUIDE.md`：新增条目的写法规范。

脚本为 UTF-8 with BOM，兼容 Windows PowerShell 5.1（`powershell.exe`）与 PowerShell 7。

## 4. 验证情况

- `dotnet build src/TextToTalk.sln -c Debug`：0 error。
- `dotnet build src/TextToTalk/TextToTalk.csproj -c Release`：0 error。
- `scripts/check-loc.ps1`：代码引用的 280 个 `Get` 键与 101 个属性键全部命中。
- 中文资源已嵌入 `zh-Hans/TextToTalk.resources.dll`（抽查 `试听`、`已切换预设`、`朗读请求触发了限流` 均存在）。
- 生成清单 `TextToTalk.json` 的描述与标语为中文。

## 5. 已知限制

- 未在游戏内实机验证（当前环境没有运行中的 FFXIV 客户端）。首次启用建议先看 `/xllog` 是否有异常。
- 上游的繁中（`zh-Hant`）与其他语言未同步维护，仅保证 `zh-Hans` 完整。
- 插件内部名称仍为 `TextToTalk`，与官方版同名；同时安装时需停用其一。
